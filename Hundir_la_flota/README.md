# Hundir la Flota — Juego en Python

Este proyecto es una recreación del clásico juego **Hundir la flota**, desarrollado completamente en **Python** como parte de mi proceso de aprendizaje en lógica de programación, estructuras de datos y modularización del código.

El objetivo principal fue practicar y mejorar mis habilidades en pensamiento algorítmico, diseño de funciones y organización de proyectos.

---

## Descripción

El jugador intenta hundir todos los barcos realizando disparos por coordenadas.  
La partida termina cuando la flota enemiga ha sido eliminada.

---

## Características del juego

- Tablero generado dinámicamente  
- Colocación aleatoria de barcos  
- Sistema de disparos con validación  
- Detección de impactos y hundimientos  
- Lógica modular organizada en varios archivos  
- Mostrar el progreso de la partida en consola  

---

## Objetivos del proyecto

Este proyecto me ha permitido trabajar:

- Estructuras de datos (listas, tuplas, matrices)  
- Funciones con responsabilidades claras  
- Uso de módulos para organizar el código  
- Control de errores y validación de entradas  
- Pensamiento lógico y resolución de problemas  

Fue un ejercicio ideal para mejorar mi base en Python e implementar un juego desde cero.
